# Elevate AI Safety Benchmark for Preventing Radicalisation to Violence

In November 2026, the Christchurch Call Foundation and Digital Public Square launched the Elevate AI safety benchmark for preventing radicalisation to violence. The benchmark is multi-turn evaluation of how LLMs respond in conversations that involve glorifying violence, building arguments in support of violent extremism, and expressing grievances connected to violent extremist ideologies. 

The first implementation includes 124 unique scenarios spanning incel violent extremism, right-wing violent extremism, nihilistic violence, and jihadist violent extremism. The November 2026 release evaluates responses from 11 models across 1,364 conversations, each consisting of up to eight user-side and assistant-side turns, respectively.

This repository hosts documentation from the initial implementation of the Elevate AI safety benchmark, including (a) the context variables and system prompt used to generate benchmark scenarios and (b) the system prompt provided to human and LLM judges evaluating conversations.
